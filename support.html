Support

How to get BetterBookmarks running, what the keyboard shortcuts are, and how to bring your existing bookmarks across. Plus honest answers to the awkward questions.

Getting started

  1. Open BetterBookmarks.app once. It shows a single window whose only job is to tell you the next step.
  2. Go to Safari → Settings → Extensions and tick BetterBookmarks.
  3. Safari asks whether it may hand the New Tab page over. Choose Use for New Windows and Tabs. If you miss the prompt, the same switch lives in Safari → Settings → General → New tabs open with, where BetterBookmarks appears in the list.
  4. Open a new tab with ⌘T. Your library appears.
Step three is asked once per Mac, and the answer does not travel through iCloud. A second Mac therefore starts out showing Safari’s own Start Page even when everything else is already set up. ⌃⌘O works either way.
Safari caches extension resources aggressively. If something looks stale after an update, switch the extension off and on again in Safari’s settings.

Keyboard shortcuts

⌃⌘OOpen BetterBookmarks. Reuses the existing tab instead of opening another.
⌘⇧DSave the current page to the last folder you used, with no interface at all.
⌘TWhatever you choose in Settings → New Tab: the start page, blank, or a URL of your own.

Safari lets you change these yourself in Safari → Settings → Extensions → BetterBookmarks. There is also a Save all open tabs command, which has no shortcut by default. You can assign one in the same place.

A web page that binds the same keys gets them first, which is why the default is ⌃⌘O and not the more obvious ⌃⌘O: several of the big web apps read that one as “new chat” and swallow it. Control and Command together is a combination pages essentially never reach for. If one does, reassign it in the settings pane above; the toolbar button works regardless.

Importing your bookmarks

Safari gives extensions no bookmarks API, so bookmarks come in as a file rather than appearing by magic. Open Settings → Import and drop a file on it.

From Safari

File → Export Browsing Data to File, tick only Bookmarks, then drop the resulting .zip straight in. No need to unzip it.

From Chrome, Firefox, Arc or anything else

Export bookmarks as HTML from that browser and drop the .html file in. The standard Netscape bookmark format is what every browser produces.

What happens before anything is written

You get a dry-run preview first: how many items will be added, how many updated, how many are already present. Nothing is written until you confirm, the whole import can be undone in one step afterwards, and importing the same file twice adds nothing.

Merge combines the file with what is already there. Replace all moves everything current to Trash first. To Trash, not to oblivion.

Syncing between Macs

Settings → Sync. Press Sync now on each Mac and they converge: the file in your iCloud Drive and the library in front of you are merged, and the result goes back up. Nothing is scheduled, so nothing moves without you.

Because it merges, the order does not matter and syncing twice does nothing the second time. Saves, renames, moves and deletions all travel. When two Macs write at the same moment iCloud keeps both versions, and the next sync folds them in rather than picking one.

When it has gone wrong

Under Recovery there are two more, and they are not sync. Take the iCloud version moves this Mac’s library to Trash and puts the iCloud one in its place. Overwrite iCloud with this Mac does the reverse, and does not keep what it replaced. Both say what they are about to do, with counts, before they do it. Reach for them when something has gone wrong, not as a way to sync.

Backups

Settings → Export offers three files. Export backup (JSON) is the lossless one. It keeps ids, ordering and timestamps, and is what a restore should use. Export without deleted is the same thing minus the soft-deleted records. Export bookmarks (HTML) is for moving into another browser.

Settings, briefly

  • Appearance follows the system, or you can pin it to light or dark.
  • Language covers English, German, Spanish, French, Turkish, Chinese and Hindi.
  • Open tabs list shows every open tab with the saved ones marked, or only the tabs you have not saved yet. Either way they can be grouped under their site.
  • New Tab decides what ⌘T shows: the full start page, a blank tab, or a specific page.

Questions

The extension does not appear in Safari’s settings.

Launch BetterBookmarks.app at least once. Safari only lists an extension after its containing app has run. If it is still missing, quit Safari completely (⌘Q) and open it again.

⌘T still shows Safari’s Start Page.

Safari has not been given the New Tab page yet. Open Safari → Settings → General and set both New tabs open with and New windows open with to BetterBookmarks.

This is asked once per Mac and the answer is not synced, which is why a second Mac can have the extension installed, enabled and fully synced and still open Safari’s own page. Until it is granted, the three choices under Settings → New Tab have nothing to act on.

Can I get Safari’s own Start Page back?

Yes, and without turning anything off: in Safari → Settings → General, point New tabs open with back at Start Page. The extension carries on working and ⌃⌘O still brings the library up when you want it.

What the extension cannot do is hand the page back by itself: once the override is declared in its manifest, Settings → New Tab → Blank is the closest it can get on its own. That is a platform rule, not a choice. Switching the extension off in Safari → Settings → Extensions also restores the Start Page, and loses nothing from your library.

The shortcut does nothing on some sites.

That site has bound the same combination and gets the key first; the shortcut reaches the extension everywhere else. Pick a different one in Safari → Settings → Extensions → BetterBookmarks. The toolbar button works on those sites in the meantime.

If the shortcut field there is empty rather than showing ⌃⌘O, Safari did not accept the suggested default and nothing is bound. Type one in; it sticks.

Does my library sync between my Macs?

Yes, through iCloud. Settings → Sync → Sync now writes one file to your own iCloud Drive and merges it with the library on the Mac in front of you. Do the same on the other Mac and both end up holding everything.

It merges rather than overwrites, so a page saved on one Mac and a folder renamed on the other both survive, and a deletion travels too. There is no schedule yet: it syncs when you ask it to.

Where is my data kept?

On your Mac, in Safari’s extension storage and IndexedDB. There is no server involved at any point. See the privacy policy.

I deleted something by accident.

Deletes are soft. Whatever you removed is waiting in Trash on the start page.

Why does it ask for the “tabs” permission?

To tell which of your saved pages are open right now, so that clicking one switches to the existing tab rather than opening a duplicate. That is the whole reason.

Safari puts a tab’s address behind website access, so it has to ask for that too. It ships no content scripts, which means nothing of it runs inside the pages you visit: it sees a tab’s address and title, and nothing else.

Does it work on iPhone or iPad?

macOS only for now.

Is $9.99 a subscription?

No. One payment, and updates come through the Mac App Store like any other app you own.
