Privacy Policy

BetterBookmarks collects no personal data, of any kind, from anyone. There is no account, no sign-in, no analytics, no crash reporting and no server component. This page explains what that means in practice.

Last updated 2 September 2026.

What is stored, and where

Your Spaces, folders, saved pages and settings are stored locally on your Mac, using Safari’s extension storage and IndexedDB. They stay on the device that created them. Nothing is uploaded, and there is nowhere for it to be uploaded to.

There is no cloud sync. Moving a library between Macs is something you do deliberately, by exporting a backup file and importing it on the other machine.

Network activity

The extension makes no network requests of its own. There is no fetch, no XMLHttpRequest and no WebSocket anywhere in it, no analytics SDK, no remote configuration and no remotely loaded code.

The one thing that touches the network is website icons: each saved page shows its site’s favicon, loaded as an ordinary image directly from that site, with a no-referrer policy. The site sees a request for its own icon and nothing about where it came from. Which icon address worked is remembered locally so the request is not repeated. No third party is involved, and no icon service is used.

Permissions

BetterBookmarks asks for three permissions and no others.

  • storage lets it keep your library and settings on your Mac.
  • tabs lets it tell which of your saved pages are open right now, so that clicking one switches to that tab instead of opening a duplicate.
  • contextMenus lets it add a save item to Safari’s right-click menu.

It requests no host permissions. It cannot read, modify or inject anything into the pages you visit, and it has no access to page content, form fields, passwords or browsing history.

Import and export

Importing a bookmark file reads that file on your Mac only. Exports are written to a location you choose. Neither operation transmits anything.

Purchases

BetterBookmarks is sold through the Mac App Store. Apple handles the purchase and shares no identifying information about you with me. I see only aggregate sales figures. See Apple’s privacy policy for how Apple handles that transaction.

Children

BetterBookmarks collects no data from anyone, including children under 13. It contains no advertising and no third-party content.

Changes to this policy

If this policy ever changes, the new version will be published on this page with a new date. Given that the answer is “nothing is collected”, changes are unlikely.
